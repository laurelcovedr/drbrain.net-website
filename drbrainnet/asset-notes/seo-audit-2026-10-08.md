# SEO audit — 8 October 2026

Site: YIWEI MEDICAL global prototype. Baseline: deployed version 23.

The audience is private (`custom`, existing allowlist retained). Search indexing and external submissions remain disabled. SEO readiness does not make the site publicly searchable.

## Findings from the authorized HTTP scan

- 29 HTML addresses returned HTTP 200, with no broken internal resource links identified in the initial scan.
- The 28 application pages shared one generic description. The printable legacy report had no description.
- All 29 HTML addresses lacked canonical URLs, social preview images, and JSON-LD.
- 27 section/detail pages streamed metadata outside the initial head. This was a rendering behavior, not absence of metadata; metadata is now emitted in the initial head for user agents.
- The sitemap endpoint returned 404. Invalid section/product addresses correctly returned 404.
- Every native image had alt text and explicit dimensions. These were preserved.
- Article source links were mostly inside client dialogs and later list entries were not initially rendered.

## Changes

- One central route registry supplies 28 distinct titles/descriptions, canonical URLs, Open Graph, Twitter cards, and schema data.
- Organization, WebSite, WebPage/AboutPage/ContactPage, breadcrumbs, product identities, and research source lists use existing authored content. No prices, ratings, endorsements, or new regulatory claims were added.
- The sitemap contains 27 current canonical application routes. It excludes the legacy interactive report, print helper, query filters, and redirected aliases. No fabricated modification dates are used.
- All 22 research entries and 16 source-PDF links are in the initial article-list HTML. The existing expandable list, study dialogs, and filters remain available.
- The printable legacy report gains metadata and a no-JavaScript link to the current PDF/report, and remains noindex.
- Fourteen images receive lossless WebP delivery copies. All decoded RGBA pixels were verified identical to their source PNGs. Combined size falls from 15,863,076 to 8,994,682 bytes (43.3%). Original files are retained. This is an asset-size result, not a measured Core Web Vitals improvement.
- Native images use asynchronous decoding; existing lazy loading and video `preload="none"` are retained.

## Validation

`node scripts/check-seo.cjs` checks unique route metadata, navigation coverage, canonical URLs, all social image paths, private robots, schema identity, all paper/PDF links, and sitemap exclusions. TypeScript and the production build must pass before deployment. An authenticated HTTP recrawl then checks rendered head metadata, resources, query canonicalization, alias redirects, sitemap, 404 responses, and anonymous access rejection.

A public launch remains a separate decision. It will require an approved production domain, removal of deliberate indexing blocks, and Search Console verification/submission. Lighthouse, public Rich Results Test, and actual search rankings cannot be assessed through a private site during this task.
