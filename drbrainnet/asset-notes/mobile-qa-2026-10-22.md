## 实际问题及修复

**研究弹窗滚动到底后，关闭按钮移出可视区。** 原关闭按钮位于滚动容器内，随正文一起滚走；Playwright 默认点击会自动滚回按钮，因此只做 `click()` 会漏检。新增真实坐标命中检查 `elementFromPoint()`，要求滚动到底后关闭按钮仍在视口且能直接命中。

- 修复前：三语言 × 四视口共 12 组均复现。见 [原始失败记录](mobile-qa-2026-10-22/scroll-before/results.json)。
- 修复：增加研究正文滚动容器；在 ≤1050px 时将关闭按钮置于独立固定区域，正文滚动不遮挡关闭按钮，也不从按钮下穿过。使用动态视口高度限制弹窗，并保留正文滚动。
- 桌面 >1050px 时正文容器使用 `display: contents`，沿用既有网格及间距；未重新设计网站。
- 修复后：12 组均通过滚动后坐标命中、触点点击关闭及 Escape 关闭检查。最终汇总见 [324 页 / 72 流程记录](mobile-qa-2026-10-22/after/results.json)。

## 交互覆盖

每种语言、每个视口均执行：

1. 打开移动导航、在长菜单中找到并点击联系入口、页面跳转后菜单关闭；重新打开后 Escape 关闭。
2. 英→中、中→西、西→英切换，并验证保留 Forcus 产品路径和正确 HTML 语言。
3. 研究内容搜索（`dementia` / `痴呆` / `demencia`）、无结果状态、清空恢复；打开研究弹窗、滚动到底、直接点击关闭、再次打开及 Escape 关闭。
4. 四产品 Dr.Brain、RealNow、AutismShield、Forcus 的联系按钮、FAQ 锚点及各四条回答。原站 FAQ 是静态问答卡片，没有虚构手风琴展开操作。
5. 联系目的切换、填写字段、无效/有效邮箱的浏览器校验、选择 AutismShield。仅使用 `qa@example.invalid`，不点击提交。
6. 报告第一页前翻禁用、后翻到第 2 页、下拉选择第 7 页、前翻到第 6 页，以及分页文字和按钮在容器内的布局。

## 复现与持续回归

```sh
cd drbrainnet
npm install --ignore-scripts --package-lock=false
npm install --no-save --ignore-scripts --package-lock=false playwright@1.62.1
npx playwright install --with-deps chromium
node scripts/run-mobile-qa.cjs
```

Linux 容器需有中文字库；CI 安装 `fonts-noto-cjk`。新增的 `.github/workflows/full-site-mobile-qa.yml` 独立运行本地测试并保留截图/JSON，包含失败时的证据上传，不包含部署步骤。

另外通过 `tsc --noEmit`、`check-evidence-search.cjs`、`check-locales.cjs` 和 `check-seo.cjs`；保留原有 16 条 FAQ、三语言结构、本地化表单字段、81 条 sitemap 地址及私有 robots 策略。
